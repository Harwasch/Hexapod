# User documentation

Written late, stubbed early. A product whose specification sheet cannot be
filled in is usually a product with a requirements gap, and you want to find
that out in week two rather than week twenty.

* `spec-sheet.md` — the published numbers for this product.
* `manual.md` — how to use it.
* `safety.md` — warnings, ratings, regulatory statements.

Pull every number from the requirements tree, not from memory. If the spec
sheet and `requirements/` disagree, one of them is wrong; find out which.
